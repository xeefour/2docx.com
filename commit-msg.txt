## การตั้งค่า Carbone (พบว่าปรับได้จาก log)

log ระบุ maxGenerationTime เท่ากับ converterFactoryTimeout
จึงเปลี่ยนผ่าน config/carbone-config.json

  converterFactoryTimeout : 60000 -> 300000  (60 วิ -> 5 นาที)
  factories              : 1      -> 3        (ทีละงาน -> 3 งานพร้อมกัน)
  bind                   : 127.0.0.1 -> 0.0.0.0

ผลที่วัดได้จริง
  - เอกสาร 100 KB (114 หน้า) ที่เดิมหมดเวลา ตอนนี้ผ่านใน 175 วินาที
  - เอกสาร 200 KB ยังหมดเวลา แม้ให้ 5 นาที จึงควรแบ่งเอกสาร
  - 3 งานพร้อมกัน: เดิม 25.9 วิ -> ใหม่ 9.4 วิ (เร็วขึ้น 2.8 เท่า)
  - RAM ปกติ 320 MB / โหมด 3 งาน 650 MB
  - พบสาเหตุที่ไม่ตรวจ API Key คือ authentication: false (ค่าเริ่มต้น)
    ต้องใช้ Enterprise จึงจะเปิดได้ จึงยังต้องมี API Gateway คุมสิทธิ์เอง

## บั๊กที่แก้ระหว่างทำ

  - healthcheck เรียก node ไม่ได้ (Carbone เป็น binary คอมไพล์แล้ว)
    เปลี่ยนไปใช้ curl
  - localhost:4000 ติด timeout จาก wslrelay.exe ค้าง
    เปลี่ยนทั้งหมด 20 ไฟล์เป็น 127.0.0.1
  - การเขียนไฟล์ .ps1 แบบไม่มี BOM ทำให้ PowerShell 5.1 อ่านไทยไม่ได้
    เพิ่ม BOM กลับแล้ว ครบ 13 ไฟล์

สร้างแม่แบบ .docx ให้ระบบเติมข้อมูลให้

คู่มือนี้อธิบายเฉพาะการทำแม่แบบไฟล์ .docx ให้ระบบนำไปเติมข้อมูลจริง แล้วส่งเอกสารกลับมาเป็น Word หรือ PDF ครบทุกขั้นตอนในหน้าเดียว ไม่ต้องไปเปิดคู่มือที่อื่น

ทุกตัวอย่างในหน้านี้ผ่านการรันจริง

ตัวอย่างทุกชิ้นถูกส่งเข้าเครื่องเรนเดอร์ตัวจริงที่ระบบใช้อยู่ แล้วอ่านข้อความจากไฟล์ที่ได้กลับมาเทียบกับค่าที่คาดไว้ ถ้าตัวไหนผิด สคริปต์ตรวจจะรายงานตกทันที ไม่ใช่ปล่อยให้ผิดพลาดไปกับเอกสารราชการ

หน้านี้สำคัญกว่าคู่มือของต้นฉบับ — ให้ยึดหน้านี้เป็นหลัก

ระบบนี้สร้างต่อยอดจาก Carbone เป็นต้นฉบับ แต่ไม่ได้ใช้ Carbone ตามที่มันเป็นทุกส่วน มีหลายส่วนที่เราพัฒนาเพิ่มขึ้นเอง เช่น การจัดการการจัดย่อหน้าภาษาไทย การตั้งภาษาไทยในไฟล์ผลลัพธ์ การแปลงเป็น PDF และส่วนประกอบในหน้าเว็บ

ถ้าสิ่งที่เขียนในหน้านี้ขัดกับคู่มือของ Carbone ให้ยึดหน้านี้ เพราะหน้านี้ทดสอบกับเครื่องที่ระบบใช้จริงแล้ว ส่วนคู่มือของ Carbone อธิบายระบบเต็มรูปแบบที่เราไม่ได้ใช้ทั้งหมด

ฉบับปัจจุบัน 0.1.0 — เลขนี้นับของคู่มือเล่มนี้เอง ไม่เกี่ยวกับเลขเวอร์ชันของ Carbone ดูรายละเอียดการเปลี่ยนแปลง

เตรียมไฟล์ .docx ก่อนใส่ tag

ปิดเครื่องหมายคำพูดอัจฉรัยก่อนเป็นอันดับแรก

ขั้นนี้สำคัญที่สุด เพราะ Word จะเปลี่ยน ' เป็น ’ ให้เอง พอ tag มีเครื่องหมายคำพูดโค้ง ระบบจะอ่านไม่ออก แล้ว tag ทั้งบรรทัดจะหายไปเงียบ ๆ

  1. ไปที่ File › Options › Proofing › AutoCorrect Options

    ใน Word รุ่นเก่าใช้เมนู Tools › AutoCorrect Options แทน

  2. เปิดแท็บ AutoFormat As You Type

    เอาติ๊ก “Straight quotes with smart quotes” ออก

  3. ตรวจด้วยตาเองอีกครั้ง

    พิมพ์ tag ที่ต้องใช้ แล้วดูว่าเครื่องหมายคำพูดเป็นตัวตรงหรือไม่ ถ้าเป็นตัวโค้ง แปลว่ายังไม่ปิด

เครื่องหมายคำพูดคู่ " ทำให้เอกสารเพี้ยน

ถ้าใช้ " ระบบจะ escape ซ้ำสองชั้น เอกสารที่ได้จะมีตัวอักษร &quot; โผล่มาให้เห็นเป็นข้อความธรรมดา ต้องใช้ ' เดี่ยวเท่านั้น

tag ต้องอยู่ในชิ้นเดียวกัน

อย่าเพิ่งแบ่งสี หรือเพิ่มการขีดเส้นใต้กลาง tag ให้พิมพ์ tag ให้เสร็จก่อนแล้วค่อยจัดรูปแบบทั้งบล็อก ถ้าต้องการสีเฉพาะตัวอักษร ให้ใช้ Font Color ทั้งบล็อกแทนการไล่เฉพาะบางตัวอักษร

เขียน tag

ระบบนี้ใช้ tag แบบเดียวเท่านั้น คือ {d.ชื่อข้อมูล} เมื่อเติมข้อมูลแล้ว tag จะหายไปและกลายเป็นค่าจริงในเอกสาร

เขียนแบบนี้ได้หมายเหตุ
{d.ชื่อ}ได้รูปแบบเดียวที่ใช้ได้
{ชื่อ}ไม่ได้ต้องมี d. นำหน้าเสมอ
{c.ชื่อ}ไม่ได้ระบบนี้ไม่มีที่ให้ดึงข้อมูลผ่าน c.
{t(คำ)}ไม่ได้ระบบนี้ไม่ได้ตั้งค่าการแปลภาษาไว้
{o.lang=th}ไม่ได้ตัวเลือกในเทมเพลตไม่มีผลกับระบบนี้

กฎของ tag

  • ชื่อข้อมูลห้ามมีช่องว่าง — {d.ชื่อ เต็ม} จะทำให้ทั้งย่อหน้าหายไป ถ้าจำเป็นต้องมีช่องว่าง ให้ครอบด้วยคำพูดเดี่ยว: {d.'ชื่อ เต็ม'}
  • ใช้เครื่องหมายคำพูดเดี่ยวเท่านั้น — 'ข้อความ' ไม่ใช่ "ข้อความ"
  • ต่อ formatter ด้วยเครื่องหมาย : — เช่น {d.ยอด:formatN(2):round(0)}
  • ค่าคงที่ในวงเล็บไม่ต้องครอบคำพูด — substr(0,5) ไม่ใช่ substr('0','5') ยกเว้นข้อความที่มีช่องว่างหรือเครื่องหมาย

{.ชื่อ} นอกวงจะไม่ทำงาน ระบบจะปล่อยให้ข้อความ {.ชื่อ} โผล่อยู่ในเอกสาร ให้ใช้ {d.ชื่อ} เสมอเมื่ออยู่ระดับบนสุด

อ้างค่าจากชั้นที่อยู่ข้างบน

tagหมายถึง

จัดรูปแบบข้อความ

ใส่หลังชื่อข้อมูลด้วยเครื่องหมาย : แล้วตามด้วยชื่อ formatter

formatterทำอะไรตัวอย่างและผลจริง
substr(เริ่ม,จบ)ตัดข้อความ{d.ข้อความ:substr(0,5)} → Hello
substr(เริ่ม)ตัดจากตำแหน่งนั้นจนจบ{d.ข้อความ:substr(6)} → Carbone
prepend('ข้อความ')เติมข้างหน้า{d.ชื่อย่อ:prepend('บริษัท ')} → บริษัท Carbone
append('ข้อความ')เติมข้างท้าย{d.ชื่อย่อ:append(' จำกัด')} → Carbone จำกัด
replace('เดิม','ใหม่')แทนคำในข้อความ{d.ข้อความ:replace('Carbone','คาร์โบน')} → Hello คาร์โบน
ellipsis(จำนวน)ตัดให้เหลือความยาวที่กำหนดแล้วเติมจุด{d.ข้อความ:ellipsis(8)} → Hello Ca...
lenนับจำนวนอักขระ{d.ข้อความ:len} → 13
print('ข้อความ')ขึ้นข้อความที่กำหนดเสมอ ไม่สนใจค่าที่มี{d.หมายเหตุ:print('- ไม่มี -')} → - ไม่มี -
unaccentตัดเครื่องหมายเอกับเฉพาะภาษาอังกฤษ{d.ข้อความ:unaccent} → Hello Carbone
arrayJoin('ตัวคั่น')รวมอาร์เรย์ของข้อความธรรมดาให้เป็นบรรทัดเดียว{d.รหัส:arrayJoin(', ')} → A01, B02, C03
ภาษาไทยไม่มีตัวพิมพ์ใหญ่เล็ก

upperCase lowerCase ucFirst และ ucWords จะไม่เปลี่ยนอะไรเลยเมื่อใช้กับข้อความไทย ตัว formatter กลุ่มนี้ใช้ได้ผลเฉพาะข้อความภาษาอังกฤษหรือตัวเลข

arrayJoin ใช้ได้เฉพาะอาร์เรย์ของข้อความธรรมดา

ถ้าอาร์เรย์เป็นรายการของวัตถุ จะได้ผลเป็น [object Object] และถ้าใส่ไว้ในวงซ้ำ จะได้เพียงค่าของรายการนั้น ไม่ใช่รวมทั้งอาร์เรย์

formatC(ทศนิยม)จัดรูปแบบเงิน ตามสกุลเงินที่ระบบตั้งไว้125,000.50 €
round(ทศนิยม)ปัดเศษปัดจาก -1234.5678 เป็น -1235
absเอาค่าสัมบูรณ์ ตัดเครื่องหมายลบออก1234.5678
add(ค่า)บวกบวกค่าคงที่ หรือบวกค่าจากชั้นบนด้วย add(.ชื่อ)
sub(ค่า)ลบ125000.5 − 250 = 124750.5
mul(ค่า)คูณ250,001
div(ค่า)หาร31,250.13

รายการนี้ทดสอบแล้วว่าใช้ไม่ได้จริงกับระบบนี้ ไม่ใช่แค่ไม่แนะนำ — ใส่แล้วจะได้ผลผิดหรือเอกสารล้มทั้งฉบับ

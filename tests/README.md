## ข้อจำกัดที่ต้องรู้

| เรื่อง | ผลกระทบ |
|---|---|
| **ต้องเติมข้อความก่อนฉีดรูป** | สลับลำดับแล้วเติมข้อความไม่ได้ |
| **LibreOffice หมดเวลา 60 วิ** | เอกสารซับซ้อนมากหมดเวลา 60 วิ |
| **API Key ไม่ถูกตรวจ** | ห้ามเปิด Carbone ออกสู่ภายนอกโดยตรง |
| **รูปต้องฉีดเอง** | Carbone เวอร์ชันฟรีใส่รูปไม่ได้ |
| **ชื่อฟิลด์ต้องมี `d.`** | `{ชื่อ}` ไม่ถูกแทน ต้องเป็น `{d.ชื่อ}` |
| **PDF เก็บสระเป็น glyph แยก** | ค้นข้อความใน PDF ไม่เจอ แต่เปิดดูด้วยตาถูกต้อง |

## ลำดับการทำงานที่ถูกต้อง

```python
# 1. เติมข้อความก่อน
docx = carbone_render(template_id, data, "docx")

# 2. แล้วค่อยฉีดรูป
injector = ImageInjector(docx)
injector.set("ตราสัญลักษณ์", seal_path)
injector.run()
injector.save(final_docx)

# 3. แล้วค่อยแปลงเป็น PDF
pdf = carbone_convert(final_docx, "pdf")
```

**สลับขั้น 1 กับ 2 = เติมข้อความไม่ได้**

## ถ้าจะเริ่มงานจริง

ลำดับที่แนะนำ:

1. สร้าง **API Gateway** คุมสิทธิ์เอง (เพราะ Carbone ไม่ตรวจ)
2. ก๊อป `lib/docx_image_injector.py` ไปใช้ในโปรเจกต์จริง
3. ทำแม่แบบ `.docx` โดยใส่ช่องคำอธิบายรูป (Alt Text) เป็นชื่อช่อง
4. ทดสอบกับเอกสารจริง 3-5 ฉบับ เทียบกับที่ทำใน Word
5. ดูตัวอย่างที่ `part-08-full-flow/output/` เป็นแบบ

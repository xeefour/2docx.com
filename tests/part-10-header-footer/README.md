## แก้เส้นหยักแดงใต้ข้อความไทย (สำคัญมากสำหรับงานราชการ)

### อาการ

เปิดไฟล์ DOCX ใน Word แล้วข้อความไทยมีเส้นหยักแดงใต้ทั้งหมด โดยเฉพาะในส่วนหัวและท้ายเอกสาร

### สาเหตุ

Word ตรวจการสะกดตามภาษาที่ "ประกาศ" ไว้ในไฟล์ (แท็ก `w:lang`)
ถ้าไม่มีการระบุภาษา Word จะคิดว่าเป็นภาษาอังกฤษ แล้วตีเส้นแดงใต้ข้อความไทย

ตรวจแล้วว่าแม่แบบที่สร้างด้วย python-docx **ไม่มีแท็ก `w:lang` เลย**
ทั้งในเนื้อหาหลัก ส่วนหัว และส่วนท้าย

**หมายเหตุ:** ปัญหานี้เกิดกับ Word เท่านั้น — PDF ที่แปลงออกมาไม่มีเส้นหยักแดง

### วิธีแก้

มี 2 วิธี เลือกตามความเหมาะสม

| วิธี | ผลลัพธ์ | เหมาะเมื่อ |
|---|---|---|
| **ตั้งภาษาไทย** | Word ตรวจสะกดเป็นภาษาไทย (เส้นแดงหายถ้าสะกดถูก) | ต้องการให้ Word ช่วยตรวจสะกด |
| **noProof** | บอก Word ว่า "ไม่ต้องตรวจ" ไม่มีเส้นหยักแดงแน่นอน | เนื้อหาเป็นชื่อเฉพาะ เลขรหัส หรือข้อความที่ตั้งใจเขียนแบบนี้ |

### โค้ด

```python
from thai_proofing import fix_document

# ตั้งภาษาไทย (Word ยังตรวจสะกด แต่เป็นภาษาไทย)
fix_document("แม่แบบ.docx", "ผลลัพธ์.docx", skip_proof=False)

# หรือไม่ต้องตรวจสะกดเลย
fix_document("แม่แบบ.docx", "ผลลัพธ์.docx", skip_proof=True)

# แก้เฉพาะส่วนหัว/ท้าย (เนื้อหาหลักปล่อยไว้)
fix_document("แม่แบบ.docx", "ผลลัพธ์.docx",
             parts=("header", "footer"))
```

### ผลการทดสอบ

| ส่วน | ตั้งภาษาไทย | noProof |
|---|---|---|
| เนื้อหาหลัก | 36 จุด | 36 จุด |
| ส่วนหัว | 1 จุด | 1 จุด |
| ส่วนท้าย | 3 จุด | 5 จุด |

**เนื้อหาไม่เสียหาย** — ทดสอบแล้วข้อความยาวเท่าเดิมทุกประการ (2,010 ตัวอักษร, ไทย 1,742)

### ทำไมส่วนหัว/ท้ายมีปัญหามากกว่าเนื้อหาหลัก

เนื้อหาหลัก Word มักตั้งภาษาให้เองตอนพิมพ์
แต่ส่วนหัว/ท้ายมักถูก "วาง" ลงไปโดยตรง (copy จากเอกสารอื่น หรือสร้างด้วยโค้ด)
จึงไม่มีการตั้งภาษามาให้

**แนะนำ:** ถ้าเอกสารไหนเตือนตอนเปิด ให้รัน `fix_document()` หนึ่งครั้งทันที จะหายถาวร

## วิธีสร้างเลขหน้าอัตโนมัติ

ใน Word ใช้ **แทรก → เลขหน้า → ด้านบนหรือด้านล่าง**

รูปแบบที่ทดสอบ: `หน้า {PAGE} จาก {NUMPAGES} หน้า`

### ถ้าเขียนแม่แบบด้วยโค้ด

```python
from docx import Document
from docx.oxml.ns import qn
from docx.oxml import OxmlElement

def add_field(paragraph, code, size=14, bold=False):
    """แทรกฟิลด์ของ Word เช่น PAGE, NUMPAGES"""
    # เริ่มฟิลด์
    r = paragraph.add_run()
    fc = OxmlElement("w:fldChar")
    fc.set(qn("w:fldCharType"), "begin")
    r._r.append(fc)

    # คำสั่งฟิลด์
    r = paragraph.add_run()
    it = OxmlElement("w:instrText")
    it.set(qn("xml:space"), "preserve")
    it.text = f" {code} "
    r._r.append(it)

    # แยกส่วนค่า
    r = paragraph.add_run()
    fc = OxmlElement("w:fldChar")
    fc.set(qn("w:fldCharType"), "separate")
    r._r.append(fc)

    # ค่าเริ่มต้น (จะถูกคำนวณใหม่ตอนเปิด)
    paragraph.add_run("1")

    # จบฟิลด์
    r = paragraph.add_run()
    fc = OxmlElement("w:fldChar")
    fc.set(qn("w:fldCharType"), "end")
    r._r.append(fc)
```

**สำคัญ:** ต้องมี `fldChar` ครบ 3 ส่วน (begin / separate / end) ไม่งั้น LibreOffice จะไม่คำนวณค่าให้

## วิธีทำ "หน้าแรกต่างจากหน้าถัดไป"

**ใน Word:** แทรก → ส่วนหัวและท้าย → ส่วนหัว → ตัวเลือก **"หน้าแรกต่างจากหน้าถัดไป"**

**ด้วยโค้ด:**
```python
section = doc.sections[0]
section.different_first_page_header_footer = True   # เปิดใช้

# หัวหน้าแรก
h1 = section.first_page_header
h1.paragraphs[0].add_run("ชื่อหน่วยงาน")

# ท้ายหน้าแรก (ไม่มีเลขหน้า)
section.first_page_footer.paragraphs[0].add_run("(หน้าแรก)")

# ท้ายหน้าอื่น (มีเลขหน้า)
f = section.footer
f.paragraphs[0].add_run("หน้า ")
add_field(f.paragraphs[0], "PAGE")
```

**ทำไมเอกสารราชการถึงนิยมใช้:** หน้าแรกมีหัวเอกสารประจำเอกสารอยู่แล้ว (ชื่อหน่วยงาน เลขที่เอกสาร)
ไม่ต้องซ้ำทุกหน้า และมักไม่ต้องการเลขหน้าบนหน้าแรก

## ข้อควรระวับ: ขอบกระดาษต้องเผื่อที่ส่วนหัว/ท้าย

ถ้าขอบบนชืดกว่าส่วนหัวอยู่ เนื้อหาจะไปทับส่วนหัว

```python
section.top_margin = Cm(3.0)        # ขอบบน
section.header_distance = Cm(1.5)   # หัวเอกสารอยู่ห่างจากขอบกระดาษ 1.5 ซม.
```

ค่าที่ใช้ในการทดสอบ:
- ขอบบน 3.0 ซม. · ส่วนหัว 1.5 ซม. · เหลือพื้นที่เนื้อหา 1.5 ซม.
- ขอบล่าง 2.5 ซม. · ส่วนท้าย 1.5 ซม.
- ขอบเย็บซ้าย 3.0 ซม. (มาตรฐานเล่มเอกสารราชการ) · ขวา 2.0 ซม.

## ข้อจำกัดที่ยังไม่ได้ทดสอบ

- เลขหน้าในรูปแบบอื่น เช่น `1-1`, `หน้าที่ 1/3`, หรือเลขฐานอื่น
- เลขหน้าเริ่มที่หน้าเลขอื่น (เช่น ข้างหน้า แถบภาษา)
- หน้าคู่ (เลขหน้าแยกซ้าย-ขวา ตามเล่มเอกสาร) — เอกสารราชการไทยใช้บ่อย
- ส่วนหัวที่มีตารางหรือรูปภาพ
- การเปลี่ยนเลขหน้าเมื่อเนื้อหายาวมากจนเพิ่มหน้า (เอกสารจากระบบอาจเพิ่มหน้าเอง)
- หัวกระดาษที่มีเงื่อนไข (แสดงเฉพาะบางหน้า)

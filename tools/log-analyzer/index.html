⚠ ยังตั้ง MiniMax API key ไม่เรียบร้อย

ส่วน “ภาพรวม” และ “เหตุการณ์น่าสงสัย” ใช้ได้ตามปกติ แต่ปุ่ม วิเคราะห์ด้วย AI จะยังใช้ไม่ได้ จนกว่าจะใส่คีย์

วิธีตั้ง (1 ขั้นตอน):

  1. เปิดไฟล์ .env ที่รากโปรเจกต์ แล้วเพิ่มบรรทัดนี้
    MINIMAX_API_KEY=<คีย์ของคุณ>
  2. ปิดแล้วเปิด server ใหม่ (Ctrl+C แล้วรัน start.cmd อีกครั้ง)

ไฟล์ .env ถูก .gitignore ไว้แล้ว คีย์จะไม่หลุดเข้า git

server จะอ่านจากไฟล์แรกที่เจอ: tools/log-analyzer/.env → .env รากโปรเจกต์ → dokploy-infra/.env
